# Daily Routine Android App

A clean black/white/grey routine tracker starter project.

Included:
- Add daily tasks with customizable time
- Exercise flag
- Complete tasks by tapping them
- Completed tasks disappear from the active list
- Completion percentage
- Streak counter
- Celebration overlay when all tasks are completed
- Notification permission request

Next production step: persist tasks/completions with DataStore/Room and schedule exact daily notifications with AlarmManager, including a midnight reset.
